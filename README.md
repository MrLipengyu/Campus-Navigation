## 📖 项目简介

本项目是一个基于 **Qt 6 Graphics View Framework** 开发的 2.5D 校园探索与智能导航模拟系统，面向《C++程序设计》课程设计。

系统以真实校园为蓝本，构建了包含多个建筑物和完整路网的校园地图。用户可以操控角色在校园中自由漫游，通过 **Dijkstra 或 A* 寻路算法** 规划路线，体验角色平滑沿路径行走的导航过程。此外，系统内置了丰富的环境模拟与互动元素，如昼夜随时间切换、全局天气粒子特效、多终点 TSP 近似规划以及 NPC 对话功能，打造沉浸式的校园探索体验。

## 🏗️ 项目架构

项目采用了高度解耦的设计，将数据处理、界面显示与逻辑控制分离：

```text
CampusNavigation/
├── main.cpp                  # 程序入口，完成全局设置与核心模型挂载
├── CMakeLists.txt            # CMake 构建配置文件
│
├── core/                     # 核心算法与数据模型层（纯C++逻辑，无UI依赖）
│   ├── map/                  #   CampusMap(地图解析与管理), Building(建筑数据结构)
│   ├── graph/                #   Graph(图数据结构：Node + Edge 邻接表实现)
│   └── pathfinding/          #   Dijkstra, AStar 等图论最短路径算法及 TSP 求解
│
├── graphics/                 # 可视化引擎层（基于 Qt Graphics View）
│   ├── MapView.h/cpp         #   地图主视图，封装 16ms 游戏主循环、渲染管线、输入响应
│   ├── CharacterItem.h/cpp   #   玩家图元，负责位置插值、精灵切片动画和状态更新
│   ├── WeatherSystem.h/cpp   #   高性能的全局天气粒子系统（Rain/Snow）
│   └── NpcItem.h/cpp         #   NPC 交互图元，处理与玩家的位置触发距离
│
├── controller/               # 业务控制层（MVC 架构中的 Controller）
│   └── NavigationController  #   桥接视图与算法，管理起点/途经点、切换算法，并驱动角色导航
│
├── database/                 # 数据持久化层
│   └── DatabaseManager.h/cpp #   SQLite DAO，提供校园建筑数据的 CRUD 接口
│
├── ui/                       # 用户交互界面层
│   ├── MainWindow.h/cpp      #   主窗口：布局侧边栏、状态栏、地图视图、信号槽绑定
│   └── DialogWidget.h/cpp    #   弹出式交互面板组件（如 NPC 对话、信息展示）
│
└── resources/                # 静态资源（通过 Qt RCC 编译进可执行文件）
    ├── campus_map.png        #   底图资源
    ├── character.png         #   玩家行走序列帧图
    ├── map_data_fuben.json   #   初始路网节点、边与建筑拓扑数据
    └── resources.qrc         #   Qt 资源描述文件
```

## 🚀 一键编译运行

### 方法一：命令行（推荐）

```bash
# 1. 克隆仓库
git clone <仓库地址>
cd CampusNavigation

# 2. 配置 CMake（请将 CMAKE_PREFIX_PATH 替换为你的实际 Qt 安装路径）
cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.5.3/msvc2022_64"

# 3. 编译项目
cmake --build build --config Release

# 4. 运行程序
./build/Release/CampusNavigator.exe
```

> **注意**：首次运行会在程序同级目录自动创建 `campus_data.db` 数据库文件，无需手动初始化数据。

### 方法二：Qt Creator（IDE 快捷方式）

1. 打开 **Qt Creator**
2. 选择菜单 `文件` → `打开文件或项目`
3. 选中项目根目录下的 **`CMakeLists.txt`**
4. 在弹出的 Kit 配置中，勾选对应的 Qt 6.5+ 编译套件
5. 等待 CMake 初始化配置完成
6. 点击左下角 ▶ **运行** 按钮（或快捷键 `Ctrl+R`）

### 智能导航流程

1. **查找目标**：在右侧控制面板的搜索框输入目的地名称（支持自动提示），按 `Enter` 快速定位。
2. **设定起点**：点击地图上的建筑节点 → 在弹出的信息面板中点击 **"设为起点"**。
3. **设置途经点/终点**：点击其他目标建筑 → 点击 **"添加途经点"**，可依次添加多个。
4. **选择算法**：在面板中可切换 **Dijkstra** 或 **A*** 寻路算法。
5. **开始导航**：点击 **"开始导航"**，系统将规划最佳路线顺序，并驱动角色沿高亮路径平滑行走。
6. **重置状态**：点击 **"清空"** 按钮可清除所有标记点及当前路线。

## 🧮 核心算法解析

### 最短路径计算（Dijkstra / A*）

- **数据层**：基于 `core::Graph` 实现的邻接表（`std::unordered_map<int, Node>`）。
- **执行逻辑**：
  1. `CampusMap` 读取 JSON 加载路网连通性与权值（物理距离）。
  2. 建筑物通过其唯一的 `entrance_node_id` 与路网连接。
  3. `Pathfinder` 根据选择的算法（如 Dijkstra 结合最小优先队列，或启用了启发式的 A* 算法），计算起始节点到目标节点的最短路径，并返回节点序列。
- **视图层**：将节点序列转化为屏幕坐标系下的折线，并启动逐点移动动画。

### 多目标游览规划（TSP 近似解）

- **场景**：当用户选定起点及多个途经点/终点时触发。
- **算法设计**：采用**贪心最近邻（Greedy Nearest Neighbor）算法**。
- **过程**：
  1. 将起点作为当前点。
  2. 遍历所有未访问的目标节点集，计算它们与当前点的图论最短距离。
  3. 选取距离最近的目标，规划出两点间的完整路径片段，并将该目标标记为已访问且设为新的当前点。
  4. 重复此步骤直到遍历所有目标。最终将所有路径片段拼接为一条连贯路线。
